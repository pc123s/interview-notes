## 1、基本概念

### 1.1 信息熵

在机器学习中，假设当前数据D有y类，k类数据占比$p_k$。则信息熵为
$$
En(D)=\sum{p_k*log_2{p_k}}
$$
当pk取1或者0的时候，熵最小，pk取均匀分布的时候（1/k）熵最大，不确定性最大。

### 1.2 信息增益(ID3算法)

我们就可以进一步了解信息增益（Information Gain），它衡量的是我们**选择某个属性进行划分时信息熵的变化**（可以理解为基于这个规则划分，不确定性降低的程度）。
$$
Gain(D,a)=Ent(D)-\sum {\frac{|D^v|}{D}Ent(D^v)}
$$


信息增益描述了一个特征带来的信息量的多少。在决策树分类问题中，信息增益就是决策树在进行属性选择划分前和划分后的信息差值。

缺点：1、信息增益更容易选择**类别较多**的变量。2、信息增益只对离散变量好用

### 1.3 信息增益率（C4.5）

​	C4.5提出了信息增益率的做法。具体的公式为：
$$
Gain\_ratio(D,a)=\frac{Gain(D,a)}{IV(a)} \\
IV（a）=\sum{\frac{|D_v|}{|D|}}{log_2{\frac{|D^v|}{|D|}}}
$$
​     c4.5客服了 ID3更倾向于选择类别更多的变量。信息增益率相比信息增益，多了一个衡量本身属性的分散程度的部分作为分母，而著名的决策树算法C4.5就是使用它作为划分属性挑选的原则。



### 1.4 **基尼指数**（Gini Index）

​	当然除了信息熵增益以外，数学上用于计算信息量（或者纯度）衡量的指标也会用到基尼指数来表示数据的不纯度。基尼指数越大，数据越不纯 。
$$
Gini(D)=1-\sum{p_k^2} ....k=1,2,...y
$$
属性A的gini系数为
$$
Gini(D,a)=\sum_{i=1}^{v}{\frac{|D_v|}{|D|}Gini(D)}
$$
选择使得基尼系数划分为最小的属性。

​        那么gini系数相比于c4.5有哪些优势呢：

（1）gini系数计算简单，由于gini系数没有进行log计算，所以计算效率上比信息熵增益要高。

（2）c4.5虽然对类别较多的变量选择倾向相比于id3有所缓解，但是仍然有偏向于更多变量的概率。gini系数则是用纯度来进行划分，相比于c4.5的划分效果更好，并且为了弥补纯度的损失，gini系数可以用一个变量多次划分。

### 1.5 例子

### 1、信息增益例子



| 特征1 | 特征2 | 类别 |
| ----- | ----- | ---- |
| 1     | 1     | 是   |
| 1     | 0     | 是   |
| 0     | 1     | 否   |
| 0     | 0     | 否   |
| 1     | 1     | 否   |

在我们的例子中，类别有两种：是和否。在数据集中，是出现的概率为 3/5，否出现的概率为 2/5。因此，整个数据集的信息熵为：
$$
Entropy(s)=-(\frac{2}{5}*ln(\frac{2}{5})+\frac{3}{5}*ln(\frac{3}{5}))
$$
对于特征1来说：

当特征1取值为0时，数据集中有两个样本：

| 特征1 | 特征2 | 类别 |
| ----- | ----- | ---- |
| 0     | 1     | 否   |
| 0     | 0     | 否   |

当特征1取值为1时，数据集中有三个样本：

| 特征1 | 特征2 | 类别 |
| ----- | ----- | ---- |
| 1     | 1     | 是   |
| 1     | 0     | 是   |
| 1     | 1     | 否   |

$$
entropy(特征1=0)=1ln1=0 \\
entropy(特征1=1)=-(\frac{2/3}ln(2/3)+1/3ln(1/3))\\
gain(特征1)=3/5*entropy(特征1=1)+2/5*entropy(entropy(特征1=0))\\
info\_gain(特征1)=entropy(s)-gain(特征1)
$$



然后分别计算特征1和特征2的信息增益，选择信息增益最大的作为第一次切分。

对于信息增益率来说，我们只需要计算IV即可。这里同样以特征1为标准。那么IV特征1的公式为

# 二、baging模型

## 2.1 bagging模型适用于哪些模型

通过对数据集进行有放回的随机抽样来创建多个子样本数据集，然后在每个子样本数据集上训练一个基模型，最后将这些基模型的预测结果进行平均（对于回归任务）或投票（对于分类任务）。Bagging能够减少模型的方差，提升整体性能，特别是在基模型表现不稳定的情况下。

1、适合用Bagging的模型

(1)**高方差模型**（不稳定模型）：

- **决策树**：决策树模型非常适合使用Bagging，因为决策树对训练数据中的噪声和变化非常敏感，容易过拟合。Bagging可以通过平均多个决策树的结果来减少过拟合，提高模型的泛化性能。

- **随机森林**：这是Bagging的一个特例，通过对多个决策树模型进行Bagging，并在构建树的过程中进一步引入随机性（例如在每个节点分裂时仅考虑部分特征），进一步提高模型的泛化能力和性能。

- **神经网络**：虽然较少见，但在某些情况下，神经网络也可以通过Bagging来减少过拟合，尤其是在网络结构较深的情况下。

- **K近邻（KNN）**：Bagging在KNN中的应用可以减小训练数据对结果的影响，提高分类器的稳定性。

2、不适合bagging的模型

（1）**低方差模型**（稳定模型）：

- **线性回归**：线性回归模型通常是低方差的，因为它假设数据具有线性关系，且参数估计稳定。Bagging对线性回归的效果有限，因为线性回归本身并不容易过拟合。
- **岭回归、Lasso回归**：这些是带有正则化的线性回归模型，已经通过正则化技术控制了模型复杂度和方差，Bagging的效果同样有限。

（2）**支持向量机（SVM）**：SVM模型在处理高维数据和寻找决策边界时已经非常稳定，Bagging对其效果不明显，且SVM训练时间较长，进行多次训练会大大增加计算成本。

3、总结

Bagging最适合应用于高方差模型（如决策树），通过平均多个模型的结果来减少过拟合，提高泛化能力。而对于低方差模型（如线性回归、正则化回归）和已经稳定的模型（如SVM），Bagging的效果有限，且可能带来额外的计算开销。总之，Bagging的主要目的是减少方差，所以对于本身方差不大的模型，Bagging不会带来显著的性能提升。

# 三、常见的机器学习的项目的考点

## 3.1 什么是knn，knn进行分类的原理是什么

knn即k近邻算法，主要的思路是有一个样本数据集合，每个样本都对应的有相应的数据标签，利用数据标签对样本最邻近样本的划分。

主要的步骤有：

（1）扫描所有样本，计算测试样本和每个样本的距离。

（2）选择前k个最小距离的样本。

（3）根据这k个标签进行投票，得到最后的分类结果。

2、调参的主要步骤

k的选择，k会决定最后整个分类的效果，最后根据k个点的投票来决定最终的分类效果。

（1）一般来说，k越小越容易过拟合，假如k=1，离点最近的只是一个噪声点的话，那么测试样本就很容易被判别为一个错误样本。

（2）如果k很大的话，比如k=N，那么完全是用整个样本进行预测了，此时模型已经完全失效了，即不管距离怎么设置，最后的分类结果一定为以类别数量较多的类别作为最终的标签。

（3）所以一般会采用k折交叉验证的方式进行k最终参数的确定。

1、网格搜索

网格搜索很简单，对多个参数设置一个范围，遍历对所有参数进行排列组合，选择效果最好的一个排列组合作为最后的结果。

```
# 定义超参数空间
param_grid = {
    'n_estimators': [10, 50, 100],
    'max_depth': [None, 10, 20],
    'min_samples_split': [2, 5, 10],
    'min_samples_leaf': [1, 2, 4],
    'bootstrap': [True, False]
}
# 生成所有参数组合
def generate_param_combinations(param_grid):
    keys, values = zip(*param_grid.items())
    print(keys)
    print(values)
    #exit()
    for combination in product(*values):
        yield dict(zip(keys, combination))
```
